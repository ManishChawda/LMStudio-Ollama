# LM Studio and Ollama — Local LLM Experiments

Python learning project exploring local Large Language Models (LLMs) using LM Studio and Ollama.

## Overview

- Connect to local LLM servers from Python.
- Experiment with LangChain integrations.
- Run interactive prompts and model tests.
- Compare model responses and benchmark performance.
- Explore Windows-hosted models accessed from Ubuntu.

## Requirements

- Python 3.10+
- LM Studio and/or Ollama
- Python virtual environment
- Required Python packages for the selected script

## Configuration

Update the server URL and model name in the relevant script to match your environment.

Do not commit API keys, passwords, private configuration, or environment files.

## Project Contents

The Python scripts demonstrate different approaches to interacting with LM Studio and Ollama, including interactive prompts and benchmarking.

## Disclaimer

Educational project for local LLM experimentation. Scripts may require adjustments for your installed models, server endpoints, and package versions.
